# Java Functions Practice

## About
This repository contains Java programs based on user-defined methods and functions. These programs are created for practice and to understand the basic concepts of Java methods.

## Topics Covered

- User-defined methods
- Methods with parameters
- Methods without parameters
- Methods with return values
- Methods without return values (`void`)
- Square and cube of a number
- Hypotenuse of a right-angled triangle
- Printing characters using `String.repeat()`
- Circle area and circumference
- Reading input using `Scanner`
- Rounding values using `Math.round()`
- Using built-in methods such as `Math.sqrt()`, `Math.pow()`, and `Math.PI`

## Programs

### 1. Square and Cube
Calculates the square and cube of a number entered by the user.

### 2. Hypotenuse
Calculates the hypotenuse of a right-angled triangle using the Pythagorean theorem and rounds the result to two decimal places.

### 3. Print Line
Prints a specified character a given number of times using the `String.repeat()` method.

### 4. Circle Area and Circumference
Calculates the area and circumference of a circle using its radius and rounds the results to two decimal places.

### 5. Different Types of Methods
Demonstrates four types of methods:
- No parameter and no return value
- No parameter with return value
- Parameter and no return value
- Parameters with return value

## Technologies Used

- Java
- Scanner
- Math Class
- User-defined Methods

## Learning Purpose

The purpose of these programs is to improve Java programming skills and understand how methods work, how parameters are passed, and how values are returned.
